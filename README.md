# 日月食模拟器 · Eclipse Simulator

真实星历驱动的日-月-地三维模拟器：**月球本影/半影锥实时扫过地球**，
自动判定日食/月食类型，一键跳到下一次日月食。

属于"太空科普系列"第三弹（遨游太阳系 → 潜入深渊 → 日月食模拟器），
也是给 Solar-Wanderer 上游 ROADMAP 里"食影系统"的一个技术预演。

## 运行

```bash
npm install --registry=https://registry.npmmirror.com
npm run dev        # → http://localhost:5175（Node ≥ 20.19，本机 nvm use 22.22.0）
npm run build      # 静态产出 dist/
node tools/test-scan.mjs   # 食扫描器回归测试（Node 直接跑，无需浏览器）
```

## 能做什么

- **真实定位**：太阳（Meeus 低精度）+ 月球（Schlyter 模型 + 主摄动项）星历，
  任意时刻的地心黄道位置、月相、日月角距、月球黄纬
- **食判定**：新月/满月窗口内按"本影轴对地心瞄准距离 vs 地球半径"分类
  日全食/日环食/日全环食/日偏食；月全食/月偏食/半影月食
- **一键跳食**：黄经差过零检测（每朔望月一次，永不漏检）+ 二分细化到秒级，
  800 天窗口内扫描下一次日食/月食
- **可视化**：月球本影锥（真实长度 ~379,000 km）与半影锥、地影锥、
  本影暗斑在地球表面移动、月食时月球变红
- **时间控制**：实时 / 1分每秒 / 1时每秒 / 1天每秒，播放暂停

## 扫描器校验（node tools/test-scan.mjs）

对照 NASA 日月食目录，从 2026-10 起连续 4 次日食/月食全部命中：

| 模拟器输出 | 真实事件 | 偏差 |
|---|---|---|
| 2027-02-06 15:57Z 日环食 | 2027-02-06 日环食 | ~2 分钟 |
| 2027-08-02 10:07Z 日全食 | 2027-08-02 日全食 | 分钟级 |
| 2028-01-26 日环食 / 2028-07-22 日全食 | 全部命中 | 类型全对 |
| 2027-02-20 半影 / 2027-08-17 / 2028-01-12 / 2028-07-06 月食 | 命中 | 边缘类型可能差一档 |

## 精度声明（诚实边界）

- 判定为**地心近似**：时刻误差可达数十分钟，食分边缘的类型（全/环、偏/半影）可能差一档
- 真正的食预报需要角秒级 Besselian 元素 + 地面定点计算——那是 v2 的事：
  - 接入 VSOP87/ELP2000 完整级数（±3000 年）
  - 顶ocentric 视图：站在城市街道上看日食过程
  - NASA 式食带地图（kml 路径绘制在地球贴图上）

## 架构

```
src/
  astro/ephemeris.js      # 星历 + 食几何 + 扫描器（纯函数，Node 可测）
  components/
    SceneCanvas.jsx       # Three.js 场景（命令式 API：update(jdMs) / setView）
    Hud.jsx               # 左上信息面板（rAF 命令式刷新，零重渲染）
    Controls.jsx          # 底部时间控制条
  App.jsx                 # 唯一 rAF 主循环（与 deep-sea 同一套模式）
```

注意：后台标签页 rAF 被浏览器冻结是正常行为（省 CPU），切回前台即恢复。
